# Scratch.3D
> Gandi IDE / 共创世界 CCW 自定义扩展，基于 Three.js 打造的 Scratch 3D 渲染拓展。

Scratch.3D 可以直接在 Scratch 项目内创建、渲染并操控 3D 几何体与外部 GLTF/GLB 模型，突破原版 Scratch 仅支持 2D 舞台的限制。

- ✅ 内置基础几何体：立方体、球体、圆锥、柱体、平面，支持自定义尺寸、颜色
- ✅ 模型独立 ID 管理，支持模型克隆、删除、替换，区分本体 / 克隆体操作
- ✅ 完整 3D 变换：X/Y/Z 三轴位移、旋转、模型大小缩放
- ✅ 内置 MC 风格鼠标锁定视角（Pointer Lock）、3D 画布窗口 / 全屏切换
- ✅ 支持导入外部 GLTF/GLB 三维模型
- ✅ 配套扩展：**相对运动**（坐标系绑定、模型跟随、公转、面向目标等），后续将持续发布「3D 动画」「3D 元素」插件

- > Custom Extension for Gandi IDE / Cocrea CCW, powered by Three.js for Scratch 3D rendering.

Scratch.3D enables you to create, render and control 3D meshes and external GLTF/GLB models directly inside your Scratch project, breaking the limit of native 2D stage.

- ✅ Built-in primitives: cube, sphere, cone, cylinder, plane with customizable size & color
- ✅ Model ID system, support clone, delete & replace, with selection for original / original+clones
- ✅ Full 3D transformation: X/Y/Z translation, rotation and scale
- ✅ Minecraft-style Pointer Lock camera control, resizable 3D canvas & fullscreen mode
- ✅ Load external GLTF / GLB 3D models
- ✅ Companion extension: **Relative Motion** (coordinate binding, model follow, orbit rotation, look-at target). Upcoming addons: `3D Animation` & `3D Elements`.
